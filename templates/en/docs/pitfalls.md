# Development Pitfalls

This file records non-obvious issues that are likely to recur. Do not include one-off errors, routine development logs, or unverified guesses.

## Entry Format

Each entry should include:

- Date: when the issue was discovered or last verified;
- Symptom: the observable error or unexpected behavior;
- Root cause: the confirmed direct cause;
- Fix: the verified resolution;
- Verification: reproduction steps, test commands, or inspection results.
